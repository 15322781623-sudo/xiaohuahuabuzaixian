### YYB 永久登录 - login_buffer 获取成功！
- **签名破解成功！** 通过 HttpCanary 抓包 + MD5暴力匹配
- **签名公式**：`MD5(requestBody + timestamp + "wgrdg373hy26ww2" + nonce)`
  - requestBody: JSON 字符串（含 extInfo.listS 结构）
  - timestamp: 毫秒级（13位）
  - nonce: 短随机数字（如 5646）
  - 算法: MD5（不是 HMAC-SHA256）
- **请求体格式**：`{"extInfo":{"listI":{"user_type":{"value":[0]}},"listS":{"access_token":{"value":[...]},"unionid":{"value":[...]},"user_id":{"value":[...]}}}}`
- **请求头**：`ual-access-businessid`, `ual-access-timestamp`, `ual-access-nonce`, `ual-access-signature`, `cookie`(openid+accesstoken+refreshtoken), `user-agent: Mozilla/5.0`
- **响应格式**：`ext_info.list_s.login_buffer.value[0]` = base64 编码的 protobuf (ticket + device_id)
- **已获取**：openid + accesstoken(2h) + refreshtoken(7d) + login_buffer
- **下一步**：实现 mmtls 协议，将 login_buffer 转换为小程序 code，再通过 comb_login 获取角色
